# Commit style

- Do NOT add `Co-Authored-By: Claude ...` or any AI attribution trailers to commit messages.
- Commits are authored solely by the developer.
- Message format: imperative subject line, blank line, then bullet-point body if needed.
- Subject line ≤ 72 characters.
